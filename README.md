MyFirstApp — Hello World Android Application
Overview

This is a beginner-level Android application built in Kotlin using Jetpack Compose, developed as Experiment 1 for the Android Development lab. The app demonstrates the fundamental structure of an Android project and renders a personalized greeting message on screen.

Concept / Technology
Language: Kotlin
UI Toolkit: Jetpack Compose (modern declarative UI framework for Android, replacing the older XML-layout approach)
IDE: Android Studio
Minimum SDK: API 24 (Android 7.0 "Nougat")
Build system: Gradle (Kotlin DSL — build.gradle.kts)

Jetpack Compose lets the UI be described directly in Kotlin code using @Composable functions instead of separate XML layout files. The app's entry point is MainActivity.kt, where setContent { } renders the Compose UI tree when the activity is created.

Scenario

The app demonstrates the classic "Hello World" scenario, extended to show a personalized greeting. On launch, the app displays "Hello Shubham!" on the screen, generated by passing a name value into a reusable Greeting composable function.

Key Code
kotlin
@Composable
fun Greeting(name: String, modifier: Modifier = Modifier) {
    Text(
        text = "Hello $name!",
        modifier = modifier
    )
}
